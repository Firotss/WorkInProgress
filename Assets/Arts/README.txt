Card texture sprites (Red_Texture, Green_Texture, Blue_Texture)
--------------------------------------------------------------
- Red   = attacker cards (Bear, Wolf)
- Green = spell cards (Heal Potion, Bag of Holding)
- Blue  = defender cards (Wall)

To use as sprites: Select each .jpg in Unity, set Texture Type to "Sprite (2D and UI)",
then assign Red/Green/Blue to the Deck component's Card Sprites fields (PlayerDeck, EnemyDeck).
